# 총 플레이타임과 던전 시간

> 후속 변경: 현재 저장 버전5에서 던전 소요시간의 공개/저장/표시는 정수 초로 변경됐다. 총 플레이타임의 잔여 초 정책은 유지한다. Docs/ClearRank/README.md에 랭크·버림 규칙과 검증을 기록했다.

2026-10-20 사용자 승인 제안1·2 구현. 검토 당시 조사·정책은 DevelopmentProposal.md에 보존한다.

## 총 플레이타임

StatusSaveFile이 게임 시작 전에 자동 생성되어 MainMenu부터 모든 씬에서 유지된다. 씬에 기존 저장 컴포넌트가 있어도 공용 인스턴스는 하나다. Editor의 씬 단독 실행에도 적용된다.

- 실제 실행 경과시간을 측정한다. 월드맵·상점·길드·모듈·체크포인트·클리어·게임 내 일시정지를 포함하며 프로그램 종료 후 시간은 더하지 않는다.
- 숫자 play_time_minutes가 완성된 누적 분이다. play_time은 호환용 누적 시간:분 문자열이며24시간을 넘어도 시간 부분을 초기화하지 않는다. 예:135:26→135:27.
- play_time_remainder_seconds는0~60 미만의 잔여 초다. 메모리에서만 계속 갱신하고 매분·기존 게임 저장·정상 종료/앱 중단 저장에 함께 기록한다.20초 실행 후 정상 종료하고40초 실행하면 합계1분이 된다.
- AdventureRecordDataView가 기존 Adventure Record/PlayTimeValue에만 숫자 총 시간을 시간 : 분으로 표시한다. 열린 페이지는 저장 알림에서, 닫힌 페이지는 다시 열 때 갱신한다. 다른 UI 배치는 변경하지 않았다.

## 던전 시간

같은 공용 서비스가 현재 씬과 active_run/checkpoint의 런 ID를 확인하고, 선택된 미완료 던전에서만 초 단위로 측정한다. 던전 시간은 기존과 같이 Unity의 시간배율을 따르므로 timeScale=0에서 멈춘다. 총 시간은 별도 실제 경과시계로 계속 증가한다.

| 시점 | 동작 |
| --- | --- |
| 첫 입장 | 새 런0초부터 시작 |
| 던전 플레이 | 메모리의 clear_time_seconds 누적 |
| 체크포인트 | 현재 시간을 상태와 한 번에 저장한 뒤 측정 중지. 지연 씬 로드 프레임도 추가하지 않음 |
| 체크포인트 복귀 | 해당 던전의 저장된 run_time_seconds부터 재개 |
| 다른 던전 | 떠나는 런을 캡처하고 선택 던전의 시간을 복원 |
| 클리어 | pending_clear로 측정 중지, ClearScene에서 한 번만 확정 |
| 결과 화면 | 이번 런의 clear_time_seconds 표시. 첫 실제 기록은 기본값과 무관하게 저장하고 이후 더 짧은 값만 best_clear_time_seconds 갱신 |
| 종료/앱 중단 | 두 시간을 같은 저장에 포함 |

DungeonRunTracker2D는 기존 씬 참조와 FlushTimeToSave 호출을 위한 호환 어댑터다. 실제 측정은 씬의 어댑터 배치 유무에 의존하지 않는다. 기존 serialized saveInterval=1은 더 이상 사용하지 않으며 초당 파일을 쓰지 않는다. 중복 어댑터는 자신만 제거해 같은 GameManager의 다른 컴포넌트를 유지한다.

## 파일 저장과 실패

타이머 정기 저장은 완성된 분 경계마다 한 번이며 긴 프레임으로 여러 분이 지났어도 한 번으로 합친다. 피격·해체·구매·체크포인트·클리어 등 기존 게임 저장은 별도로 발생한다. 이미 해당 분의 시간까지 정상 저장했다면 같은 분의 타이머 저장을 반복하지 않는다.

저장 실패 시 측정된 메모리 값은 유지한다. 정기 저장은5초 뒤 재시도하며 같은 시간을 다시 더하지 않는다. 던전 상태 트랜잭션은 시간 캡처 후 복제/원자적 저장하고 실패하면 상태만 이전으로 돌아간다. 종료/앱 중단 저장은 StatusSaveFile 하나가 담당하며 어댑터에서 중복 저장하지 않는다. 강제 종료 시 마지막 정상 저장 이후의 시간은 반영되지 않을 수 있다.

## 버전4 이행

기존 버전2 체크포인트 이행과 버전3 던전 기록을 유지하면서 총 시간 필드를 추가했다. play_time_minutes가 없는 저장의 유효한 시간:분 문자열은 숫자 총 분으로 변환한다. 빈 문자열은0이다. 해석할 수 없는 값은 임의로 추정하지 않고 play_time_legacy_unparsed에 원문을 남긴다. 로드 시 원자적 교체의 직전 정상본 백업도 사용한다. 버전4부터 숫자 분이 우선이며 문자열은 자동 생성한다.

새 게임 템플릿 Assets/StreamingAssets/savefile.json만 수정했다. 사용자 활성 저장 파일은 개발 도구로 수정/실행 테스트하지 않았으며 다음 정상 실행에서 기존 Load 경로가 이행한다. 씬·프리팹·DB·맵·이미지·프로젝트 설정은 변경하지 않았다.
