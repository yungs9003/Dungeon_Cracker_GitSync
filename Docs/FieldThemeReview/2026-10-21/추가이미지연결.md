# ice/fire 테마 이미지 추가 방법

현재 빈 테마 이미지는 기존 그림을 그대로 표시한다. 새 이미지를 전달하면 기존 번호와 방향을 확인한 뒤 아래 카탈로그의 빈 참조에 연결할 수 있다. 자동 선택 코드를 다시 만들 필요는 없다.

## 빈 항목 채우기

1. 새 PNG를 `Assets/Sprites/FieldThemes/Ice` 또는 `Fire` 폴더에 넣는다. 기존 타일과 같은 이름을 사용하면 찾기 쉽다. 예: 벽 8번은 `001-001-8.png`.
2. Unity Import Settings를 `Sprite (2D and UI)`·`Single`·100 Pixels Per Unit·가운데 Pivot으로 설정한다. 현재 타일은 100×100이며, 원본과 테두리 방향을 맞춘다. 현재 테마 이미지처럼 Point 필터·압축 없음 설정을 사용할 수 있다.
3. `Assets/Resources/Data/MapSpriteThemes.asset`을 선택한다.
4. Entries에서 **Original**이 해당 기존 Sprite인 행을 찾아 Ice 또는 Fire 빈 칸에 새 Sprite를 연결한다. Original 참조는 유지한다.
5. 맵을 다시 생성하거나 플레이를 재시작한다. 기존 Sprite/assetNo/direction에 대응하는 새 그림이 선택된다. 한쪽 테마만 추가해도 다른 쪽은 기존 그림을 유지한다.

비어 있는 기존 11종:

| 구분 | 기존 파일 |
| --- | --- |
| 벽 | 001-001-8.png, 001-001-9.png, 001-001-12_0.png |
| 스위치 | 002-002-0.png, 002-002-1.png |
| 기타 | 102-002-0.png, 102-005-0.png, 102-009-0.png, 102-010-0.png, 102-011-0.png, 103-012-0.png |

## 선택 규칙

맵 JSON의 `field_effect.type`을 사용한다. `ice`는 Ice, `fire`와 기존 `burn`은 Fire, 값 생략/`none`/알 수 없는 값은 원본 그림이다. 대소문자와 양끝 공백은 정리한다. 피해량이 0이어도 테마는 선택된다.

같은 원본 Sprite를 쓰는 프리팹·자식 장식·발견 전 벽은 같은 대응표를 사용한다. 최초 grid/3F 생성, 함정 발견/재숨김, 해체 후 새 바닥/주변 벽/숨김 벽/WallVisual, 스위치 대체 바닥에도 적용된다.

제공된 추가 구멍 `IMG_4937.png / IMG_4958.png`는 빈 기존 항목과 다르다. 기존 구멍 0~4에 없는 새 구조라, 사용하려면 별도 번호/프리팹 Variant와 맵 사용 위치를 결정해야 한다. 현재 구현에서는 보류했다.

개발 기록 및 실제 검증 결과는 `Docs/개발과정.md`와 `Docs/Rollback/2026-10-21-field-themes/Validation`에 보관한다.
