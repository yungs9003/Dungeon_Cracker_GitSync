# WorldMap 원본 크기 지도·드래그·지점 확대

> 이 문서는 최초 구현 기록이다. 버튼 제거·팝업 닫힘 복귀·이미지 경계·관성을 반영한 현재 동작은 [후속 수정 안내](2026-10-17-inertia-and-return.md)를 참고한다.

2026-10-17 적용. 기존 `Assets/Scenes/WorldMap.unity`에서 고정 배경 대신 아래 구조를 사용한다.

```text
Canvas (Constant Pixel Size / Scale Factor 1)
├─ WorldMapViewport (Image, RectMask2D, WorldMapPanZoomUI)
│  ├─ MapContent (기존 BG, 지도 Image / 3172×1984)
│  │  └─ Buttons (지도 전체를 따라가는 컨테이너)
│  │     └─ Button1 (기존 DUNGEON_001 버튼, WorldMapFocusTargetUI 추가)
│  └─ ResetMapView (원래 크기 버튼)
├─ DungeonPopupPanels (기존 팝업)
└─ PausePopupRoot (기존 일시정지)
```

## 동작

- `Assets/Sprites/UI/WorldMap`의 제공 PNG를 사용한다. 원본 파일은 3172×1984이고, Importer의 기본 최대 크기를 4096으로 올려 원본 해상도를 보존한다. 그림 픽셀/GUID는 유지했다.
- 최초 배율은 1이다. 지도 1픽셀을 화면 1픽셀로 표시하므로 화면보다 큰 부분은 잘려 보인다. 화면에 지도를 억지로 맞추거나 축소하지 않고 드래그로 나머지 영역을 탐색한다.
- 지도 위에서 왼쪽 버튼을 누르고 드래그하면 지도와 모든 지점이 함께 움직인다. 드래그를 놓으면 멈춘다. 지도 가장자리의 지점도 중앙에 올 수 있도록 바다색 여백을 허용하며, 지도 전체가 화면 밖으로 빠지지는 않게 제한한다.
- 지점 버튼을 누르면 그 지점을 **하단 메뉴를 제외한 지도 Viewport 중앙**에 맞추며 부드럽게 확대한다. 기본은 0.5초/1.6배다. 반복 클릭해도 1.6배를 계속 곱하지 않고 목표 배율로 맞춘다.
- 이동/확대가 끝나면 기존 DUNGEON_001 팝업을 연다. 확대가 보이기 전에 팝업이 화면을 덮지 않도록 기존 OpenPopup 호출을 지점의 On Focused 이벤트로 이동했다. 던전 ID·팝업 내용·입장 처리는 유지한다.
- 확대 중 드래그하면 확대와 예약된 팝업 호출을 취소한다. 다른 지점을 선택하면 마지막 선택을 따른다. 지점 위에서 드래그한 뒤 손을 놓는 동작은 클릭으로 처리하지 않는다.
- 오른쪽 위 **원래 크기** 버튼은 배율 1과 시작 중심 위치로 부드럽게 돌아간다. 하단 메뉴/상태창/일시정지/저장 기능은 기존 구조를 사용한다.

## 조절 및 지점 추가

`WorldMapViewport > WorldMapPanZoomUI`:

| 항목 | 기본값 | 의미 |
| --- | ---: | --- |
| Focus Duration | 0.5 | 중앙 이동·확대 시간(초) |
| Max Zoom | 3 | 지점 확대의 최대 배율 |
| Content / Map Image | MapContent | 지도와 지점들이 함께 움직이는 대상 |
| Bottom Bar | 기존 BottomPanel | 메뉴의 실제 높이에 맞춰 지도 Viewport 하단을 제외 |

각 버튼의 `WorldMapFocusTargetUI`:

- Map View: 같은 WorldMapViewport의 컨트롤러.
- Focus Zoom: 해당 지점을 선택했을 때의 배율. 기본 1.6.
- On Focused: 확대 완료 후 호출할 동작. 현재 기존 ButtonPopupLink.OpenPopup을 연결했다. 확대만 원하면 이 이벤트의 팝업 호출을 제거하면 된다.

`MapContent/Buttons` 아래에 버튼을 추가하거나 기존 Button1을 복제해 위치를 정한다. 좌표는 지도 중심을 (0,0)으로 한 원본 픽셀 단위다. 예를 들어 원본 이미지의 왼쪽 위 기준 (x,y)를 지도 좌표로 옮기면 `(x - 1586, 992 - y)`다. 이미지의 해당 위치와 마커가 함께 움직인다.

새 버튼의 On Click은 `WorldMapFocusTargetUI.Focus`에 연결하고, 기존 즉시 OpenPopup 호출은 On Focused 쪽으로 옮긴다. `ButtonPopupLink`의 dungeonId와 popup은 해당 던전에 맞게 지정한다. 단순 복제 시 기존 ID가 함께 복사되는 점을 확인한다.

`Tools > Dungeon > Configure WorldMap Pan and Zoom`은 기존 BG/Buttons 및 팝업 연결을 기준으로 구조를 구성하는 도구다. 이미 구성된 구조에서는 지점의 기존 확대 설정과 완료 이벤트를 보존하며, 중복 포커스 리스너를 추가하지 않는다. 기본 지도/리셋 구조를 다시 구성할 수 있으므로 씬에서 별도로 바꾼 배치가 있으면 먼저 보관한다.

## 코드·검증 자료

- `Assets/Scripts/App/UI/WorldMapPanZoomUI.cs`: 원본 크기, 드래그, 이동 제한, 부드러운 중앙 정렬/확대, 취소/리셋, 메뉴 영역 제외.
- `Assets/Scripts/App/UI/WorldMapFocusTargetUI.cs`: 지점의 배율과 완료 이벤트.
- `Assets/Editor/WorldMapViewBuilder.cs`: 씬 연결 도구.

원본 코드 6개 어셈블리 컴파일과 분리 Play Mode 검사 20개를 통과했다. 실제 텍스처 크기/1:1 표시, 마커 동반 이동, 클릭/확대/완료 순서, 중간 위치/배율, timeScale=0, 반복/연속 선택, 가장자리 중앙 정렬, 드래그/비활성화 취소, 원래 크기 복귀와 이동 제한을 확인했다. 검증 씬은 저장 서비스를 만들지 않아 사용자 저장 파일을 읽거나 쓰지 않는다.

검증 도구는 `Temp/WorldMapView`, 수정 전후 사본·범위 manifest·컴파일/Unity 로그·PNG는 `Docs/Rollback/2026-10-17-worldmap-pan-zoom`에 있다. `Validation/worldmap-native.png`, `worldmap-focus-middle.png`, `worldmap-focus.png`, `worldmap-reset.png`에서 흐름을 확인할 수 있다. 1280×720/1920×1080/2560×1080의 실제 렌더도 보관했다. 원본 씬을 직접 Play해서 사용자 저장 파일과 함께 실행한 검증은 아니다.

기존 수정 파일은 WorldMap 씬과 지도 Importer meta 두 개다. 다른 씬·공통 메뉴 프리팹·팝업/저장 코드·원본 이미지·DB/맵/함정은 변경하지 않았다. Unity가 씬 저장 중 자동으로 덧붙인 저장 컴포넌트의 기본 JSON 캐시는 적용본에서 제외해 기존 저장 컴포넌트 블록도 보존했다.
