# 테마 함정 코드 등록과 map_002 배치

침강·분출의 최신 연출 및 Inspector 조절값은 [용암 연출 조정](2026-10-15-lava-visuals.md)을 참고한다.

네 테마 함정과 생성용 얼음 결정의 `.prefab`/`.meta`를 `Assets/Resources/Prefabs` 바로 아래로 이동했다. 원래 GUID와 프리팹 내용을 유지해 결정 생성 참조와 사용자가 조절한 값이 보존된다. 빈 ThemeTraps 폴더와 폴더 meta는 정리했다.

| 코드 | 이름 | 피해 타입 | 피해 | 넉백 거리 | 바닥 파괴 |
| --- | --- | --- | ---: | ---: | --- |
| 102-016 | 용암 | burn / 화상 | 16 | 0 | 불가 |
| 102-017 | 분출 | burn / 화상 | 20 | 0.3 | 불가 |
| 102-018 | 빙판 | 없음 | 없음 | 없음 | 불가 |
| 102-019 | 얼음 결정 | ice / 냉기 | 12 | 0.3 | 불가 |

DB는 `Assets/Resources/Data/db.json`의 traps 배열에 추가했다. 빙판의 비어 있는 피해 타입·피해량·넉백은 JSON null이다. 기존 DB 레코드와 다른 배열은 유지했다. 생성되는 결정만 기존처럼 독립적으로 파괴할 수 있고 바닥은 남는다.

피해 코드는 프리팹/부모 이름에서 자동으로 찾는다. 분출과 결정의 0.3칸 넉백은 기존 마지막 이동 방향의 반대 방향으로 적용한다. 용암의 총 원시 피해 16은 기존 2초 침강 동안 기본 4씩 4회로 분배한다.

화상·냉기는 기존 `IFieldEffectDamageReceiver` 경로를 사용한다. 따라서 DamageSystem의 화상 장비 반감 등 기존 규칙이 적용되며 필드 피해와 동일하게 직접 피격 카운트를 사용하지 않는다. 수신 컴포넌트가 없는 대상은 Health에 직접 적용한다. 밀치기·당기기의 보호 상태에서는 피해와 넉백이 차단된다. 기존 physical/magic/true 피해 처리는 유지한다.

## 맵 배치

실제 경로는 `Assets/Resources/Maps/DUNGEON_001/map_002.json`이다.

| 기존 타일 | 좌표 | 변경 코드 |
| --- | --- | --- |
| 낭떠러지 2칸 | 0203, 0603 | 102-016 용암 |
| 일반 바닥 1칸 | 0304 | 102-017 분출 |
| 일반 바닥 1칸 | 0703 | 102-019 얼음 결정 |
| 나머지 일반 바닥 14칸 | 0004, 0104, 0204, 0302, 0303, 0402, 0502, 0503, 0504, 0604, 0605, 0701, 0702, 0704 | 102-018 빙판 |

총 grid 70칸, 플레이어 시작 좌표 0004, relation 4개, assetNo, direction 및 나머지 타일은 유지했다. 시작점도 요청한 일반 바닥 치환 규칙에 따라 빙판이다. map_001과 다른 던전의 map_002는 변경하지 않았다.

JsonBlockBuilder2D에서 네 코드를 기존 바닥 함정의 숨김/발견 Sprite 교체 대상에서 제외해 자체 바닥 Sprite, 용암 예고 마스크와 서리 표시가 유지되도록 했다.

## 확인 방법

기존 DUNGEON_001 진행으로 두 번째 JSON 맵에 진입하거나, 검토용 씬에서 빌더의 JSON 경로를 `Maps/DUNGEON_001/map_002`로 지정하면 된다. 원본 게임 씬의 시작 맵 설정은 바꾸지 않았다.

적용 전후 사본과 변경 목록, 컴파일 및 별도 Unity 검증 결과는 `Docs/Rollback/2026-10-15-theme-map-002`에 보관한다. 과거 `2026-10-09/README.md`는 코드 부여 전 제작 시점의 구조·조절 안내다.

실제 Assets 소스 6개 어셈블리 컴파일을 통과했다. 별도 Unity 프로젝트에서 실제 프리팹·DB·맵 사본을 Resources로 로드하고 70칸 맵 생성, 생성용 결정 참조, 피해 타입·16 분할 예산·20/12 피해·0.3 넉백·빙판 무피해 및 강제 이동 보호를 포함한 45개 검사를 통과했다. 같은 검증 폴더의 `map-002-preview.png`에서 배치 렌더를 확인할 수 있다. 원본 게임 씬을 Play Mode로 실행한 검증과는 구분한다.
