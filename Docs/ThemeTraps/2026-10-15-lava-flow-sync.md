## 102-016: 실제로 내려간 만큼 가리기

침강이 시작될 때 캐릭터 Visual의 발밑 높이를 수면으로 기록한다. 이 수면은 움직이지 않으며, 캐릭터가 아래로 내려가 수면을 통과한 부분만 가린다. 0.1칸 내려가면 가려지는 높이도 0.1칸이다. 머리와 상체도 함께 내려가므로 원래 높이에 머리만 남지 않는다.

총 하강 거리는 실제 Visual 높이 + 0.02칸의 여유로 계산한다. 기존 2초 동안 전신이 잠기며, 캐릭터 크기가 달라져도 같은 방식으로 처리한다. Visual 크기는 줄이지 않는다. SortingGroup으로 해당 캐릭터의 마스크를 격리한다.

| Inspector 항목 | 현재 값 | 의미 |
| --- | ---: | --- |
| Lava Sink Duration | 2 | 전신이 내려가는 시간(초). 작을수록 빨리 잠김 |
| Lava Visual Drop | 0 | 최소 하강 거리(월드 단위). 0이면 실제 Visual 높이로 자동 계산. 이 값이 Visual 높이보다 클 때만 하강 거리가 더 길어짐 |
| Lava Damage Interval | 0.5 | 기존 피해 분배 간격 |

완료 시 안전 지점으로 복귀하고, 완료/중단 시 Visual parent·위치·배율·마스크 및 조작/물리 상태를 복원한다. 기존 용암 총 피해 16과 일반 낭떠러지의 축소 연출은 유지한다.

## 102-017: 화면 밖에서 바로 이미지 재순환

이전 풀은 위로 빠진 이미지를 너무 늦게 아래로 되돌려, 분출 0.5~0.75초 구간 등에서 바닥 쪽 빈틈이 커졌다. 반복 위치를 -1~2칸으로 조정해 2칸 표시 창 위로 빠지는 즉시 바닥 아래로 돌린다. 이미지는 기존 3개 SpriteRenderer를 계속 재사용한다.

`Segment Overlap=0.02`로 연속 이미지가 조금 겹치게 해 픽셀 경계의 미세한 틈도 방지한다. 원본 텍스처는 그대로이므로 이미지 자체의 색상 패턴은 반복된다. 기본 `Cell Rise Time=0.25` 및 첫 1칸에서 2칸으로 솟는 연출을 유지한다. 전체 타일의 예고 alpha, 대기/예고/분출 시간(2/1/1초), 피해 20과 피해 범위도 유지한다.
